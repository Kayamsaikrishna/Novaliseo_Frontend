Why Transformers Over Kalman Filters

Kalman/Factor Graph Limitations

The EKF/MSCKF assumes Gaussian noise and Markov dynamics. Neither holds: IMU noise has structured drift (non-Gaussian), and navigation errors accumulate history-dependent patterns. The factor graph SLAM can maintain a longer window but is computationally expensive and requires careful linearisation.

Most critically: Kalman-based systems cannot represent when this place has been visited before without a separate loop closure module — leading to two distinct subsystems with non-trivial interface management.

CNT Advantages

A Transformer with 512-token context maintains complete navigation history — the last ~17 seconds at 30Hz camera rate. The self-attention mechanism naturally discovers when current observations are similar to past ones (loop closure emerges without separate detection). The uncertainty head outputs calibrated covariance from the attention weights.

The SE(3) manifold parameterisation ensures rotation outputs always satisfy SO(3) constraints — no re-normalisation required, no gimbal lock, no singularities.

FUNCTION CNT_Forward(ctx: CircularBuffer[Token], T_prev: SE3) → (T_hat, Σ, plc):
  N ← ctx.size                        // up to 512
  Z ← STACK([token_embed(z) + sinusoidal_pos_enc(k)
             FOR k,z IN enumerate(ctx)])   // Z ∈ ℝ^{N×512}
  M ← causal_mask(N)                  // upper-triangular −∞ (no future)

  FOR layer IN transformer_layers:    // 8 layers × 8 heads
    Q,K,V ← layer.qkv_proj(Z)         // each ∈ ℝ^{N×512}
    A ← softmax((Q·Kᵀ / √64) + M)   // ℝ^{N×N}, causal
    Z ← layer.out_proj(concat(A·V)) + Z // residual
    Z ← layer.ffn(layer.norm(Z)) + Z

  h_k ← Z[−1]                         // last token hidden state ∈ ℝ⁵¹²

  // Pose head: manifold-aware SE(3) integration
  ξ_hat ← pose_mlp(h_k)               // twist ∈ ℝ⁶
  T_hat ← T_prev · Exp(ξ_hat)         // Sophus Exp — always valid SE(3)

  // Uncertainty head: log-parameterised positive-definite covariance
  Σ ← diag(exp(unc_mlp(h_k)))         // always PD, ∈ ℝ^{6×6}

  RETURN T_hat, Σ, {p_rev, μ_rev}

// ARFB Unified Extract + Match · DLA INT8 · ~5 ms total

FUNCTION ARFB_Extract(cam: StereoPair, mask: Tensor) → Features:
  C3,C4,C5 ← ARFB_Backbone.fwd(cam.left, cam.right)  // FPN, DLA INT8
  H_L,H_R  ← DetHead(C3,C4,C5)                        // heatmap ∈ [0,1]^{480×640}

  D_R ← L2_norm(DescHead(C3,C4).sample(kpts_R))
  RETURN Features{kpts_L, D_L, kpts_R, D_R}

FUNCTION ARFB_Match(feats: Features, map: SparseMap) → Matches:
  D_map ← map.descriptors_near(feats.kpts_L)           // FAISS IVF lookup
  A ← softmax(feats.D_L · D_map.T / √256)            // cross-attention ∈ ℝ^{512×M}

                          D_map.kpts[m[:,1]], K, σ_max=1.5)
